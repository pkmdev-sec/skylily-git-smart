# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.2.0] - 2024-01-28

### ✨ Features

- **commit**: Improved pattern detection for docs and test directories
- **changelog**: Enhanced section ordering and emoji support
- **api**: Added module exports for subpath imports

### 🧪 Tests

- Added comprehensive test suite with vitest
- 79 tests covering git, commit, and changelog modules
- 97%+ code coverage

### 📚 Documentation

- Comprehensive README with API reference
- Added examples directory with usage patterns
- Added CONTRIBUTING.md guide

### 📦 Build

- Added vitest for testing
- Added coverage configuration
- Updated TypeScript configuration

## [0.1.0] - 2024-01-28

### ✨ Features

- Initial release
- **commit**: Commit message generation from staged changes
- **changelog**: Changelog generation from commit history
- **cli**: Interactive CLI with `git-smart commit` and `git-smart changelog`
- **git**: Core git utilities for reading repository state

### 📚 Documentation

- Basic README with usage instructions
